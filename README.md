# christiaanbruinsma.github.io

First editorial website concept for Christiaan Bruinsma.

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## GitHub Pages

Publish this repository from the `main` branch, root directory.

## Project data

The project list is intentionally curated in `index.html`. JavaScript refreshes matching public repository links and descriptions from GitHub when available, while the local content remains as a reliable fallback.

## Project pages

Dedicated project pages live under `projects/`. Image Bench is available at `projects/image-bench/` and uses the shared site styles plus `assets/css/project.css`.

## Open Business Tools

The complete Open Business Tools collection is available at `open-business-tools/`. The homepage keeps a curated five-app selection in the existing editorial project-list design.
