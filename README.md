# christiaanbruinsma.github.io

First editorial website concept for Christiaan Bruinsma.

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## GitHub Pages

Publish this repository from the `main` branch, root directory.

## Project data

The project list is intentionally curated in `index.html`. JavaScript refreshes matching public repository links and descriptions from GitHub when available, while the local content remains as a reliable fallback.
